# Operations Master

医院各部门业务协同看板。当前版本基于两期小组汇报表，提供：

- 医生、护理、心理咨询、客服、营销五个部门的指标对比
- AI 经营洞察、跨部门矛盾识别与数据口径核验
- 可执行的责任部门、完成时限与移动端任务状态管理
- 月内动态试算、月末锁定的部门/员工排名治理规则
- 桌面端和移动端自适应展示

直接打开 `index.html` 即可预览，无需安装依赖。

数据治理与排名规则见 [`docs/月累计动态排名与月末正式排名规则.md`](docs/月累计动态排名与月末正式排名规则.md)。
